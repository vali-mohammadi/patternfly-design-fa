# راست‌به‌چین — RTL

لایهٔ آموزشی راست‌به‌چین این پروژه — **تنها بخشی که منبع بالادستی ندارد**. اصول قرینه‌سازی،
تایپوگرافی فارسی، تقویم، فرهنگ بصری، و دام‌های رایج اقتباس RTL.

شکل و طرح کلی این بخش در [`../../docs/decisions/teaching-layer.md`](../../docs/decisions/teaching-layer.md)
تصویب شده — شش موضوع برنامه‌ریزی‌شده، هنوز نانوشته:

1. چرا راست‌به‌چین صرفاً وارونه‌کردن نیست
2. اصول قرینه‌سازی
3. تایپوگرافی و اعداد فارسی
4. تقویم و تاریخ
5. فرهنگ بصری و زمینهٔ محلی
6. دام‌های رایج (تجمیعی)
