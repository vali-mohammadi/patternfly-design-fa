# مؤلفه‌ها — Components

راهنمای طراحی کامپوننت‌های تکی رابط کاربری — دکمه، مودال، افتادنی، فرم و مانند آن.

**منبع بالادستی:** `patternfly-4/components/`. جزئیات نگاشت در
[`../../UPSTREAM-MAP.md`](../../UPSTREAM-MAP.md).

هر صفحه از قاعدهٔ [دسته‌بندی واژگان](../../docs/decisions/terminology-rule.md) پیروی
می‌کند: عنوان صفحه فارسیِ گلوسری‌محور، بدون گلاس لاتین در تیتر؛ نام لاتین در front matter.

هنوز هیچ صفحه‌ای اینجا ترجمه نشده — منتظر [فهرست اولویت](https://github.com/vali-mohammadi/patternfly-design-fa/issues/8).
