# یکسان‌سازی کدگذاری فارسی — Persian character encoding fold

**وضعیت:** تصویب‌شده — [تیکت #15](https://github.com/vali-mohammadi/patternfly-design-fa/issues/15)
**منبع پژوهشی:** [research/area3-typographic-conventions.md §3.4](../../research/area3-typographic-conventions.md)

## مسئله

چند نویسهٔ فارسی دو راه کدگذاری متفاوت دارند که ظاهراً یکسان‌اند اما از نظر بایت متفاوت‌اند
و **هیچ فرم نرمال‌سازی یونیکد (NFC/NFD/NFKC/NFKD) آن‌ها را یکی نمی‌کند** — یعنی
`String.prototype.normalize()` این مشکل را حل نمی‌کند. جست‌وجو، مرتب‌سازی، حذف تکراری و
کلیدهای i18n بی‌سروصدا با هم مطابقت پیدا نمی‌کنند.

### یای فارسی در برابر یای عربی

`ی` (U+06CC، یای فارسی) در برابر `ي` (U+064A، یای عربی) و `ى` (U+0649، الف مقصوره). این سه
نویسهٔ مجزا هستند، بدون هیچ تجزیهٔ یکسان‌سازی‌شونده. صفحه‌کلید ویندوز سال‌ها یای عربی را
اشتباه نگاشت کرده و همین باعث شده بیش از نیمی از صفحات وب فارسی از یای اشتباه استفاده کنند.

### کاف فارسی در برابر کاف عربی

`ک` (U+06A9) در برابر `ك` (U+0643) — همان الگو.

### کسرهٔ اضافهٔ روی «ه» — ۀ

دو راه کدگذاری برای «ۀ»:
- **U+06C0 (پیش‌ترکیب‌شده)** — تجزیهٔ متعارف آن `U+06D5 U+0654` است: حرف «AE» کردی/اویغوری،
  **نه** هاء فارسی. آکادمی زبان فارسی، یونیکد فصل ۹، و CLDR هر سه صراحتاً استفاده از این
  نویسه را **منع** می‌کنند.
- **دنبالهٔ `U+0647 U+0654`** (هاء + همزهٔ بالا) — فرم توصیه‌شده توسط هر سه مرجع.

## جدول یکسان‌سازی الزامی

```
U+064A ي  →  U+06CC ی            یای عربی → یای فارسی
U+0649 ى  →  U+06CC ی            الف مقصوره → یای فارسی   (استثنا: هنگام نقل‌قول مستقیم عربی)
U+0643 ك  →  U+06A9 ک            کاف عربی → کاف فارسی
U+06C0 ۀ  →  U+0647 U+0654  هٔ    فرم پیش‌ترکیب‌شده → دنباله
U+0660–U+0669  →  U+06F0–U+06F9  ارقام عربی-هندی → ارقام فارسی   (برای نمایش)
U+06F0–U+06F9  →  U+0030–U+0039  ارقام فارسی → لاتین             (برای تجزیه/محاسبه)
U+200C (ZWNJ)  →  ∅              فقط برای کلید جست‌وجو — هرگز برای ذخیره‌سازی
```

## قاعدهٔ کاربرد — نکتهٔ حیاتی

**این یک تبدیل برای مقایسه است، نه برای محتوا.**

- نویسه‌های عربی هنگام نقل‌قول مستقیم متن عربی مجازند و نباید تغییر کنند.
- **هرگز U+200C را از محتوا حذف نکنید** — این نویسه `General_Category=Cf` دارد و توسط
  پاک‌سازها (sanitizer)، اسلاگ‌سازها و استخراج‌کننده‌های PDF بی‌سروصدا حذف می‌شود (حتی
  استخراج مستقیم PDF خودِ آکادمی زبان فارسی صفر نیم‌فاصله برگرداند). حذف آن معنای متن
  فارسی را تغییر می‌دهد.
- **نرمال‌سازی فقط برای مقایسه، هرگز برای ذخیره‌سازی.** محتوای اصلی دست‌نخورده می‌ماند؛
  یکسان‌سازی فقط در لحظهٔ جست‌وجو، مرتب‌سازی یا تولید کلید انجام می‌شود.

## پیوند با نام ماه‌ها و کسرهٔ اضافه

طبق CLDR، الگوهای قالب‌بندی («ژانویهٔ ۲۰۱۹» — با کسرهٔ اضافه) و الگوهای مستقل («۱۲ ژانویه» —
بدون کسره) نام‌های متفاوتی برای ماه دارند. کامپوننتی که فقط یک آرایهٔ نام ماه را کدگذاری‌شده
نگه دارد، تاریخ‌های فارسی نادستوری تولید می‌کند.
