# رجیستر واژگانی — Terminology register

**وضعیت:** تصویب‌شده — [تیکت #12](https://github.com/vali-mohammadi/patternfly-design-fa/issues/12)
**منبع پژوهشی:** [research/area4-ui-vocabulary.md](../../research/area4-ui-vocabulary.md)

## قاعده

**پیش‌فرض: رجیستر B (بومی‌سازی شرکت‌های بزرگ)** — رجیستر Firefox، ویندوز، اندروید و
Chromium فارسی.

**رجیستر C (صنعت محصول ایرانی) فقط زمانی رجیستر B را بازنویسی می‌کند که یکی از این چهار
شرط برقرار باشد:**

1. **نبود معادل** — هیچ واژهٔ بومی در هیچ بومی‌سازی منتشرشده‌ای یافت نشد.
2. **عدم همگرایی** — سه یا بیشتر واژهٔ بومی رقیب وجود دارد که با هم توافق ندارند؛ همین
   عدم‌توافق خود گواه است که هیچ واژهٔ بومی برنده نشده.
3. **ابهام** — واژهٔ بومی در معنای رابط کاربری مبهم یا غلط است.
4. **مرجع متفاوت** — کامپوننت طراحی واقعاً همان چیزی نیست که ویژگی سیستم‌عامل با آن نام
   بومی نامیده می‌شود.

**شرط ۴ عمداً محدود شده است.** «طراحان ایرانی جور دیگری می‌گویند» به‌تنهایی **کافی نیست** —
این خوانش قاعده را می‌بلعد و رجیستر B را در C ادغام می‌کند. شرط ۴ نیازمند نشان‌دادن است که
**مرجع** واقعاً متفاوت است، با گواه از یک نظام طراحی فارسی منتشرشده، نه صرفاً سلیقه.

**تساوی B-در-برابر-B** (دو واژهٔ بومی رقیب، بدون وام‌واژه در میان) به این ترتیب شکسته
می‌شود: قوی‌ترین گواه در بافت *نظام طراحی* اول؛ اگر باز مساوی بود، واژهٔ کم‌ابهام‌تر.
واژهٔ بازنده در گلوسری به‌عنوان معادل شناخته‌شده ثبت می‌شود، نه حذف.

**هرجا C برنده شد، گلوسری همچنان معادل بومی را ثبت می‌کند** و لایهٔ آموزشی می‌تواند آن را
نمایش دهد — این هدف آموزشی پروژه را برآورده می‌کند به‌جای پنهان‌کردن انتخاب.

## چرا نه گزینه‌های دیگر

- **سه‌شرطی (بدون شرط ۴)** در نظریه دفاع‌پذیرترین است، اما در عمل **زبانه** را برای «تب»
  تولید می‌کند — در تناقض با سونت (Sonnat)، تنها نظام طراحی فارسی منتشرشده، در جایی که
  کامپوننت واقعاً همان تب مرورگر نیست. مخاطب طراحانی هستند که یک کامپوننت را نام‌گذاری
  می‌کنند.
- **آستانهٔ همگرایی (C-گرا)** بر اساس خروجی خودش رد شد: «اسلایدر» را برای slider برمی‌گزیند
  که در گفتار آژانس‌های وب ایرانی معنای carousel هم می‌دهد — معاوضهٔ یک واژهٔ بومی روشن با
  یک وام‌واژهٔ مبهم. همچنین «بردکرامب» را برمی‌گزیند وقتی Element Plus معادل بومی روشنی
  («مسیر راهنما») دارد.

## واژگان کار‌شده

| مفهوم | واژه | مبنا |
|---|---|---|
| Button | دکمه | جهانی — صفر اختلاف در ۲۱ منبع |
| Toolbar | نوار ابزار | جهانی، بومی، تأییدشدهٔ فرهنگستان |
| Alert | هشدار | جهانی — ⚠️ فارسی بین alert و warning تمایز واژگانی ندارد |
| Pagination | صفحه‌بندی | جهانی، بومی |
| Search | جستجو | جهانی — رسم‌الخط دوگانه (جستجو/جست‌وجو) به شیوه‌نامهٔ نگارش موکول شد |
| Radio | دکمهٔ رادیویی | همگرایی کامل: گوگل، گنوم، ویکی‌پدیا، سونت |
| Card | کارت | مستقر، بدون رقیب |
| Form | فرم | مستقر، وام‌واژهٔ بومی‌شده — ⚠️ باگ GTK: نقش ARIA به «از» ترجمه شده، کپی نشود |
| Icon | نماد | **B برنده** |
| Slider | لغزنده | **B برنده** — اسلایدر در گفتار عامیانه یعنی carousel هم |
| Breadcrumb | مسیر راهنما | **B برنده** (Element Plus) |
| Tooltip | راهنمای ابزار | **B برنده** — سونت و GTK مستقل همگرا شدند |
| Switch | کلید | **B برنده** — دیوار و گنوم مستقل همگرا شدند |
| Badge | نشان | **B برنده** — Vuetify و سونت همگرا |
| Sidebar | نوار کناری | **B برنده** |
| Modal | مودال | **C — شرط ۱.** هیچ واژهٔ بومی در هیچ نرم‌افزار منتشرشده‌ای نیست. املا: مودال، نه مدال (هم‌نویسه با «مدال») |
| Accordion | آکاردئون | **C — شرط ۱** |
| Chip | چیپس | **C — شرط ۱.** ⚠️ اعتبار پایین: تک‌منبعی (سونت)، و در فارسی روزمره یعنی سیب‌زمینی سرخ‌کرده |
| Checkbox | چک‌باکس | **C — شرط ۲.** پنج واژهٔ بومی رقیب، هیچ‌کدام توافق ندارند |
| Menu | منو | **C — شرط ۳.** فهرست هم به‌معنای list و index است |
| Tab | تب | **C — شرط ۴.** کامپوننت، تب مرورگر نیست. ⚠️ زبانه همگرایی کامل پلتفرمی دارد (Chromium ۵۷۲ بار) — بحث‌برانگیزترین تصمیم این سند |
| Navigation | راهبری | **تساوی B-در-برابر-B.** راهبری (وردپرس + سونت) بر ناوبری (گنوم + ویکی‌پدیا) در بافت نظام طراحی. ⚠️ اعتبار پایین — راهبری معنای «رهبری» هم دارد |

## پیامدهای باقی‌مانده

- **نُه مفهوم هنوز واژهٔ مستقر ندارند:** toast، empty state، skeleton، data list، tertiary،
  popover، stepper، wizard، spinner. این‌ها نیاز به واژه‌سازی اصیل دارند و در مه نقشهٔ راه
  باقی می‌مانند. نکته: متن حالت خالی («داده‌ای موجود نیست») به‌طور مستقل توسط Ant، Vuetify و
  Element Plus همگرا شده، حتی اگر خودِ الگو نام ندارد.
- **Primary/Secondary/Tertiary ممکن است دوام نیاورد.** سونت اصلاً از این محور استفاده
  نمی‌کند — به‌جایش مقیاس تأکید (emphasis scale) دارد. تحت رجیستر B، معادل ثانویه «ثانویه»
  است (نه دوم/فرعی)؛ ترشری معادل مستقر ندارد.
